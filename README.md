# JET Encoding Guide

This guide can be accessed [here](https://jaded-encoding-thaumaturgy.github.io/JET-guide/).

## How to run

1. Run the following command:

    ```bash
    uv sync
    ```

2. Run the following command to host it locally with hot-reload.

    ```bash
    uv run zensical serve
    ```
